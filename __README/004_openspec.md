# 004 — OpenSpec w BrykaOBD

Przyjęty lekki format [OpenSpec](https://github.com/Fission-AI/OpenSpec) dla zachowania aplikacji.

- Wejście: [openspec/README.md](../openspec/README.md)
- Specs: [openspec/specs/](../openspec/specs/)
- Reguły agentów: [AGENTS.md](../AGENTS.md)

`__README/` = plan, referencje, procedura telefonu.  
`openspec/specs/` = normatywne **SHALL/MUST** + scenariusze.

## Znane problemy

- Bez CLI `openspec` na start — walidacja formatu „ręcznie” przez agentów wg README.
- Nie rozdmuchiwać change’y na docs-only / ikony.
