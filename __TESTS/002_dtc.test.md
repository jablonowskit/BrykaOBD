# 002 — Smoke: Mode 03 DTC

## Cel

Odczyt i kasowanie zapisanych kodów DTC przez ELM (Demo + live).

## Kroki

1. Demo PID → sekcja **Błędy DTC** pokazuje m.in. `P0301`, `P0420`.
2. **Kasuj** → dialog potwierdzenia → lista pusta.
3. (Live) Połącz ELM w aucie → **Odśwież** DTC → loguj kody Aveo / `NO DATA`.

## Automat

`./gradlew :shared:jvmTest` — `DtcParseTest`.
