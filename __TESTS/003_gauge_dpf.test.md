# 003 — Smoke: zakładki Zegary / DPF

## Kroki

1. Demo PID (telefon lub desktop).
2. Zakładka **Zegary** — prędkość 50, RPM, L/h ~5, L/100km ~10.
3. Zakładka **DPF** — zapełnienie ~45%, km od regen ~1200 (Demo).
4. Live na Aveo: DPF Mode 22 często `NO DATA` — OK, raw w logu.

## Expect

- Przełączanie zakładek bez crasha.
- DTC panel nadal pod listą PID gdy połączono.
