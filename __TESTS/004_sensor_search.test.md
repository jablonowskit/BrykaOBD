# 004 — Smoke: zakładka Szukaj / Odczyty

## Kroki

1. Demo PID (telefon lub desktop).
2. Zakładka **Szukaj** — puste pole: lista katalogu, bez podglądu live (katalog ≥20).
3. Wpisz `olej` — mniej niż 20 trafień; widać podgląd wartości (temp. oleju / ciśnienie).
4. **Dodaj** temp. oleju → napis „Dodane → zakładka Odczyty”.
5. Zakładka **Odczyty** — karta z żywą wartością; **Usuń** czyści listę.
6. Szeroki filtr (≥20) na Szukaj — bez spamowania preview.

## Expect

- Brak crasha przy filtrze / dodaj / usuń / przełączaniu zakładek.
- Live wartości dodanych czujników tylko na **Odczyty** (nie na Zegary/DPF).
